Sistema de Diseño

Referencia visual para todas las pantallas. Dirección: minimalista y cálida. Un color principal naranja para las acciones, negro y lavanda como apoyo, neutros claros para todo lo demás y un gradiente suave solo en el asistente. Pensado para personas mayores de 50: letra grande, botones amplios, pocas cosas por pantalla y palabras sencillas.

Componentes de referencia para implementación: HeroUI + Tailwind. Los tokens de abajo se mapean al tema de HeroUI.

Responsive

Desktop ≥ 1180 pxSidebar fija expandible, topbar completa, tablas con todas las columnas, POS con carrito lateral fijo.
Tablet 900–1180 pxSidebar colapsable a íconos, se oculta la búsqueda global y la caja activa. Formularios pasan a una columna cuando el contenido es < 760 px.
Móvil < 900 pxSidebar como drawer. Tablas → listas de tarjetas. POS: catálogo arriba, carrito abajo y barra fija con total + Cobrar. CTAs principales siempre visibles.
